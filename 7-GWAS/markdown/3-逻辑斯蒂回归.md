# 原理
## 1. 效应量：OR vs. BETA
* **默认 `--logistic`（不加 `--beta`）**
  输出的是每个 SNP 的 **Odds Ratio (OR)**，即每多一个风险等位基因，病例发生几率相对于对照的比值。
* **加了 `--beta`**
  输出的是每个 SNP 的 **回归系数 β**（log‑odds change），反映等位基因剂量与 logit(患病几率) 的线性关系。

两者数学关系：
```math
\mathrm{OR} = e^{\beta}, 
\quad 
\beta = \ln(\mathrm{OR})
```

## 2. P 值检验：Likelihood‐Ratio vs. Wald‐Test
* **默认模式（OR 输出）**
  PLINK 在不加 `--beta` 时，默认使用 **似然比检验（Likelihood‐Ratio Test, LRT）** 来生成 P 值：

  ```math
  \Lambda = -2\bigl[\ell(\hat\beta=0) - \ell(\hat\beta=\hat\beta_{\mathrm{MLE}})\bigr]
  \sim \chi^2_1
  ```
  其中 $\ell$ 是对数似然函数。

* **加了 `--beta`**
  PLINK 则用 **Wald 检验（Wald Test）** 计算 P 值：
  ```math
  Z = \frac{\hat\beta}{\mathrm{SE}(\hat\beta)}
  \sim N(0,1), 
  \quad 
  P = 2\bigl[1 - \Phi(|Z|)\bigr]
  ```
  这里 $\mathrm{SE}(\hat\beta)$ 是 $\beta$ 的标准误，$\Phi$ 是标准正态分布的累计函数。


## 3. 何时选用哪种？
* 如果你关心 **比值比 (OR)** 的直观含义，用默认 `--logistic` 就够；
* 如果你想要直接拿到 **回归系数 β**（便于做元分析、线性组合），加上 `--beta`；
* 注意：两者算出的 P 值不完全可比——LRT 在样本量充足时比较稳定，Wald 在 β／SE 估计良好时也很常用。

### 小结
| 选项                  | 输出效应量      | P 值检验方法         |
| ------------------- | ---------- | --------------- |
| `--logistic`        | OR         | 似然比检验（LRT）      |
| `--logistic --beta` | β (log‑OR) | Wald 检验（Z‑test） |

这样就能根据研究需求，在“直观 OR”与“灵活 β”之间做选择，同时留意两种 P 值背后的统计检验差异。

# 举例
下面用两行结果来具体示例如何解读。
## 1. rs12127425（β 输出版）
```text
CHR   SNP           BP     A1   TEST  NMISS    BETA      STAT      P
 1   rs12127425  794332    A    ADD   3135  -0.002684  -0.03465  0.9724
```
1. **A1 = A**
   指定“效果等位基因（effect allele）”为 A。模型里每多一个 A 等位基因，对数几率（log‑odds）按 BETA 调整。
2. **TEST = ADD**
   使用“加性模型”（additive model），即等位基因剂量 0/1/2。
3. **NMISS = 3135**
   共 3135 个样本有非缺失的基因型和表型，参与了这次回归。
4. **BETA = –0.002684**
   这是回归系数 $\beta$。
   * 解释：每增加 1 个 A 等位基因，logit(患病几率) 约 **下降 0.00268**。
   * 数学上：
     ```math
     \Delta \log\frac{P}{1-P} = -0.002684.
     ```
5. **STAT = –0.03465**
   Wald 统计量：
   ```math
   Z = \frac{\hat\beta}{\mathrm{SE}(\hat\beta)} = -0.03465.
   ```
6. **P = 0.9724**
   * 该 P 值基于 Wald 检验：
     $\;P = 2[1 - \Phi(|Z|)]$。
   * **0.9724 ≫ 0.05**，说明完全不显著，β 基本为 0，A 等位基因与表型没任何关联。
* 也就是说，携带一个 A 等位基因，病例相对对照的“几率比”接近 1，没有显著影响。
  
## 2. rs12127425（OR 输出版）
```text
CHR   SNP           BP     A1   TEST  NMISS     OR       STAT      P
 1   rs12127425  794332    A    ADD   3135  0.9973  -0.03465  0.9724
```
* **OR = 0.9973**
  对应于上面 β 的指数转换：
  ```math
  \mathrm{OR} = e^{\beta} = e^{-0.002684} \approx 0.9973.
  ```
  * 意味着携带一个 A 等位基因，病例相对对照的“几率比”约为 0.9973。
  * 接近 1，且 P≈0.97，不显著。

* 其余 STAT 和 P 与 β 版完全一致，因为同样的模型、同样的检验。


## 3. rs9697294（β 输出版）

```text
CHR   SNP           BP     A1   TEST  NMISS    BETA     STAT      P
 1   rs9697294  832359    T    ADD   3090  -0.4005  -2.081  0.03743
```
1. **A1 = T**
   效果等位基因为 T。
2. **BETA = –0.4005**
   每多一个 T 等位基因，log‑odds 下降 0.4005。
3. **STAT = –2.081**
   $Z = -2.081$。
4. **P = 0.03743 < 0.05**
   说明在传统显著水平下，这个位点与表型有**显著关联**。

## 4. rs9697294（OR 输出版）
```text
CHR   SNP           BP     A1   TEST  NMISS     OR      STAT      P
 1   rs9697294  832359    T    ADD   3090  0.67   -2.081  0.03743
```
* **OR = 0.67**
  $\;e^{-0.4005}\approx0.67$。
  * 意味着携带一个 T 等位基因时，病例与对照的**几率比**只有 0.67——具有**保护效应**（降低风险约 33%）。
* **P = 0.03743**
  与 β 版一致，也是基于 Wald 检验。

### 总结解读
* **β 版看的是“log‑odds 改变量”**，适合做元分析与线性组合。
* **OR 版更直观**：<1 表示**保护**，>1 表示**风险**。
* **示例**：rs9697294 的 T 等位基因
  * β = –0.4005，OR = 0.67，P = 0.037：显著保护效应。
* 而 rs12127425 的 A 等位基因
  * β ≈ 0、OR ≈ 1，P ≈ 1：无关联。
