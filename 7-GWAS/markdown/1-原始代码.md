## 1. GEN/Sample 到 PED/MAP（gtool1）

```bash
awk 'length($4)>1 || length($5)>1 {print $2}' chrH22.impute2 >> chrH22.exclude
awk 'length($4)>1 || length($5)>1 {print $2}' chrH1.impute2 >> chrH1.exclude

gtool -S --g /public/home/BaiHao/impute/chrH22.impute2 \
      --s /public/home/BaiHao/shapeit/bin/chr22.sample \
      --og chrH22.impute2 \
      --exclusion /public/home/BaiHao/impute/chrH22.exclude

gtool -G --g chrH22.impute2 \
      --s /public/home/BaiHao/shapeit/bin/chr22.sample \
      --ped chrH22_SNP1.ped \
      --map chrH22_SNP1.map \
      --chr 22 \
      --snp \
      --threshold 0.9

gtool -G --g chrT1.impute2 \
      --s /public/home/BaiHao/shapeit/bin/chrT1.sample \
      --ped chrT1_SNP.ped \
      --map chrT1_SNP.map \
      --chr 1 \
      --snp \
      --threshold 0.9
```

> **说明：** 使用 `awk 'length($4)>1 || length($5)>1 {print $2}'` 排除等位基因长度大于 1 的位点，并将对应位点 ID 输出到 `.exclude` 文件中。

## 6. logistic 回归

```bash
plink --bfile Han3 --logistic --covar Han3.cov --hide-covar --sex --out Han3
# （年龄缺失值按均值 40 填补）
plink --bfile Han3 --logistic --covar PCA.cov --hide-covar --sex --out PCA
# （协变量中不包含年龄）
plink --bfile Tibetan4 --logistic --covar Tibetan4.cov --hide-covar --sex --out Tibetan4
# （协变量中不包含年龄）
```

如果在 `--logistic` 命令中添加 `--beta` 参数，则会返回回归系数（BETA）而不是比值比。

```bash
plink --bfile Han_SNP4 --logistic --covar Han_SNP4.cov --hide-covar --sex --out Han_SNP4
plink --bfile Han_SNP4 --logistic --beta --covar Han_SNP4.cov --hide-covar --sex --out Han_SNP5
# 使用 plink2 进行广义线性模型拟合
plink2 --bfile Han_SNP4 --glm hide-covar sex --covar-variance-standardize Han_SNP4.cov --out Han_SNP4_plink2
# （年龄缺失值按均值 40 填补）
plink --bfile Tibetan_SNP4 --logistic --covar Tibetan_SNP4.cov --hide-covar --sex --out Tibetan_SNP4
plink --bfile Tibetan_SNP4 --logistic --beta --covar Tibetan_SNP4.cov --hide-covar --sex --out Tibetan_SNP5
plink2 --bfile Tibetan_SNP4 --glm hide-covar sex --covar-variance-standardize Tibetan_SNP4.cov --out Tibetan_SNP4_plink2
# （协变量中不包含年龄）
```
