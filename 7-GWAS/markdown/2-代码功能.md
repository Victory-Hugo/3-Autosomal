以下是这套脚本各部分的功能与目的概览，构成了一个典型的基因组关联分析（GWAS）流水线：

## 1. GEN/Sample 到 PED/MAP（gtool1）
**功能：**
* 将 IMPUTE2 格式的基因型（`.impute2` + `.sample`）转换为 PLINK 可读的 PED/MAP 格式。
* 首先用 `awk` 找出插补后等位基因长度大于 1 的位点（多等位基因），并将它们的 SNP ID 写入**排除列表**(**这意味着后续分析将不包括这些位点**)；
* 然后用 `gtool -G` 导出 PED/MAP。这里的`gtools`是一个用于处理基因型数据的工具，支持多种格式转换。这里的`-G`参数表示生成 PED/MAP 文件。

**目的：**
* 把插补（imputation）和分相（phasing）后的数据转换为 PLINK 能处理的文本格式，以便后续 QC 和关联分析。


## 2. 数据合并（merge）
**功能：**
* 使用 PLINK 的 `--merge-list` 参数，把多个染色体或多个样本批次的数据合并到一个二进制集（或重编码文本）中。
**目的：**
* 把汉族样本（chrH1、chrH…）和藏族样本（chrT1、chrT…）分开或合并，形成完整的样本集，方便后续统一 QC。

## 3. 信息提取（info ≥ 0.8）
```text
info ≥ 0.8
```
**功能：**
* 仅保留 IMPUTE2 输出中 INFO 分数高（≥0.8）的 SNP，生成新的二进制文件。
**目的：**
* INFO 分数反映插补可信度，高 INFO 的变异位点准确率更高，剔除低质量插补结果。


## 4. SNP 质量控制（QC）
**功能：**
1. **缺失率过滤**：
   ```text
   --geno 0.05
   ```
   保留缺失率 ≤ 5% 的位点；
2. **次要等位基因频率过滤**：
   ```text
   --maf 0.01
   ```
   保留次等位基因频率 ≥ 1% 的位点；
3. **Hardy–Weinberg 平衡过滤**：
   ```text
   --hwe 0.00001
   ```
   剔除 HWE P 值 < 1×10⁻⁵ 的位点。

**目的：**
* 去除低质或偏倚的 SNP，确保分析结果可靠、减少假阳性。


## 5. 主成分分析（PCA）
**功能：**
* 对 QC 后的基因型数据计算前 20 个主成分；
* 用 `twstats`（EIGENSTRAT6）评估每个主成分的显著性：
  ```text
  P < 0.05
  ```
  标记种群结构中的显著分量。
**目的：**
* 校正群体结构（population stratification），避免因群体分层导致的假关联；
* 选择若干显著主成分作为协变量，纳入后续回归模型。



## 6. Logistic 回归
**功能：**
* 使用 PLINK 的 `--logistic`（或 PLINK2 `--glm`）对每个 SNP 与表型（二分类）进行关联检验；
* 可选 `--beta` 输出回归系数（β）而非比值比（OR）；
* 协变量包含性别、主成分，有时填补缺失年龄为均值 40。
```text
logit(P) = β₀ + β₁·SNP + β₂·PC1 + … + βₖ·Sex
```
**目的：**
* 在校正共变量后，评估每个 SNP 与表型的独立关联，得到 P 值、OR/β。


## 7. QQ 图（检验统计量分布）
**功能：**
* 读取回归输出的 P 值，调用 `gap::gcontrol2()` 计算基因组膨胀因子 λ；
* 绘制 QQ 图，观察总体 P 值分布是否偏离理论分布。
**目的：**
* 评估假阳性率及通量校正效果，确认没有严重的系统性偏差。


## 8. 曼哈顿图（Genome-wide Scan 结果可视化）

**功能：**
* 用 R 包 `qqman::manhattan()` 绘制全基因组 SNP 的 –log₁₀(P) 分布；
* 通过自定义配色，区分不同染色体。
**目的：**
* 直观展示可能显著关联的基因组区域，便于候选基因定位。



## 9. SNPID 转换
**功能：**
* 将 PLINK2 输出中的 `CHR`、`BP` 两列拼接为新的 `SNPID`（格式：`CHR_BP`）；
* 重排列顺序、删除冗余列，输出整理好的表格。
**目的：**
* 统一标识符格式，便于后续结果整合与注释。

## 10. 分列操作（tidy data）
**功能：**
* 将原本合并在 `MarkerName` 或 `SNPID` 一列的 “CHR\_BP” 字符串，用 `tidyr::separate()` 拆分回 `CHR`、`BP` 两列。
**目的：**
* 恢复标准格式、方便按染色体和位置筛选或注释。

**整体目标：**
从插补后原始基因型数据出发，依次完成格式转换、合并、信息提取、严格 QC、校正群体结构，再进行全基因组关联检验与可视化，并最终整理输出标准格式结果，构建一条端到端的 GWAS 分析流程。

# 为什么需要进行PCA分析？

1. **识别和校正群体结构（Population Stratification）**
   不同族群或亚群之间存在**系统性的遗传差异**，如果不加以校正，这些差异可能被**误当作与表型的关联**，导致大量假阳性。PCA 可以从基因型矩阵中提取出主要变异方向（主成分），代表样本之间的遗传相似性。
2. **降维与协变量构建**
   通过选取前几个显著主成分作为协变量，纳入后续回归模型中，可以有效去除群体结构带来的混杂效应。
3. **数学原理（奇异值分解）**
   给定标准化后的基因型矩阵 $X$（行：样本，列：SNP），PCA 通过奇异值分解将其分解为：
   ```math
   X = U \,\Sigma\, V^{T}
   ```
   其中：
   * $U$ 的列就是各样本在每个主成分（PC）上的投影；
   * $\Sigma$ 是奇异值，对应每个 PC 的方差大小；
   * $V$ 则是原始 SNP 在各主成分上的载荷。
   拿第 1 个主成分举例，第 $i$ 个样本的 PC1 值就是：
   ```math
   \text{PC1}_i = X_i \cdot v_1
   ```
   这里 $v_1$ 是对应最大奇异值的右奇异向量。



# 为什么要做逻辑斯蒂回归？
1. **评估每个 SNP 与二分类表型的独立关联**
   GWAS 常见的是“病例–对照”设计，需要检测每个位点的等位基因频率在病例组 vs. 对照组是否存在显著差异。逻辑斯蒂回归可以在校正多种协变量（如性别、年龄、PC1、PC2…）后，估计该 SNP 对表型的独立效应。
2. **提供可解释的效应值 OR（Odds Ratio）或回归系数 β**
   * 如果使用默认配置，PLINK 输出的是比值比（OR）；
   * 如果加上 `--beta` 参数，则直接给出回归系数 β，便于后续元分析或与其他模型比较。
3. **统计模型**
   对于二分类表型 $Y\in\{0,1\}$，逻辑斯蒂回归模型为：
   ```math
   \log\frac{P(Y=1)}{1 - P(Y=1)} = \beta_{0}
     \;+\;\beta_{1}\,\mathrm{SNP}
     \;+\;\sum_{k=2}^{m}\beta_{k}\,\mathrm{Cov}_{k-1}
   ```
   * $\mathrm{SNP}$ 通常取等位基因剂量（0,1,2）；
   * $\mathrm{Cov}_{k}$ 包括主成分、性别、年龄等；
   * $\beta_{1}$ 的显著性检验 $P$ 值即表征该 SNP 与表型的关联强度。
