# 介绍
- `7-GWAS/conf/Example.cov`文件是一个示例的协变量文件，用于GWAS（全基因组关联研究）分析。该文件包含了样本的协变量信息，这些协变量可以用于调整GWAS分析中的混杂因素。建议使用`Excel`编辑，从`FAM`文件中获取样本ID、性别、表型信息，从`.eigenvec`文件中获得主成分信息，再结合`META`信息将更多的协变量（例如年龄等）整合到该文件中。
- `7-GWAS/pipe/1-原始代码.sh`是原始代码。可以不用。
- `7-GWAS/script/1-PCA分析.sh`用于进行PCA分析，并计算每个主成分的p值。
- `7-GWAS/script/2-GWAS分析.sh`是GWAS分析的脚本。该脚本使用PLINK1和PLINK2进行GWAS分析，并生成结果文件。它可以处理PLINK1和PLINK2的输入数据，并输出相应的GWAS结果文件。
- `7-GWAS/src/1-GWAS可视化.R`是GWAS结果可视化的脚本。该脚本使用`qqman`包生成曼哈顿图和QQ图，并保存为图片文件。它可以处理PLINK1和PLINK2的输出结果。

# 使用说明
1. 先准备好`bed，bim`和`fam`文件（注意`fam`文件需要具备**性别信息**和**表型信息**），运行`7-GWAS/script/1-PCA分析.sh`脚本进行PCA分析。
2. 然后使用`Excel`准备`cov`文件，再运行`7-GWAS/script/2-GWAS分析.sh`脚本进行GWAS分析。
3. 最后使用`7-GWAS/src/1-GWAS可视化.R`脚本生成可视化结果。
